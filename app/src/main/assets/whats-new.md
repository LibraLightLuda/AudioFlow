## AudioFlow 1.11.1

- 곡의 더보기 메뉴와 전체 플레이어에서 공개 오디오를 MP3 음악 파일로 저장할 수 있어요.
- 자동 다운로드의 ‘Wi-Fi에서만’ 옵션을 추가했어요. 기본 켜짐이며 끄면 새 자동 저장에 모바일 데이터도 사용할 수 있어요.
- Wi-Fi 전용 자동 저장은 연결될 때까지 대기하며, 사용하던 Wi-Fi가 끊기면 모바일 데이터로 전환하지 않고 재시도해요.
- 즐겨찾기·기록·플레이리스트의 목록 메뉴와 대기열에서 음악을 한 번에 모두 저장해요.
- 이미 저장된 ID·파일명을 건너뛰고 어떤 중복 파일이 있었는지 결과에 표시해요.
- 음악 저장 설정에 완청 자동 저장, 저장 결과, 내용이 같은 MP3 파일의 중복 정리를 추가했어요.
- 저장 대기열을 WorkManager로 관리하고, 앱 시작 때 새 버전이 있으면 버전마다 한 번만 안내해요.
- Android 파일 선택기로 저장 위치를 지정하고, 진행 상황 확인·취소·백그라운드 작업을 지원해요.
- 무료 오픈소스 Java LAME 인코더를 사용해 표준 MP3로 실제 변환해요. 파일 확장자만 바꾸지 않아요.
- 오디오 전용 스트림과 3시간 이내의 곡을 지원하며, 접근 제한·로그인·DRM을 우회하지 않아요. 저장할 권한이 있는 콘텐츠에 사용해 주세요.
- 표준 192 kbps를 기준으로 저장하며 낮은 샘플레이트는 128 kbps를 사용해요. 원본보다 음질이 높아지지 않으며 재생용 EQ·공간 효과·배속은 파일에 적용하지 않아요.
- 동시에 한 곡, 원본 512MiB·결과 256MiB·곡당 30분으로 제한해요. 실패·취소 시 임시 파일을 정리하며 바이트 단위 이어받기는 지원하지 않아요.
- 이전 버전의 재생 오류 수정과 라이브러리·가사·감상 도구를 유지해요. 이번 검증도 실기기 대신 에뮬레이터에서 진행해요.
