# 실기기 확인 절차

현재 사용자가 허용한 검증 범위는 에뮬레이터입니다. 아래 항목은 실제 휴대전화에서 통과했다고 보고하지 않습니다.

1. USB 디버깅을 허용한 테스트 기기에서 `pwsh tools/device-check.ps1 -RunAutomation`을 실행합니다. 운영 앱과 별개인 `.debug` 패키지만 설치합니다.
2. 기존 운영 버전 위에 같은 인증서의 새 APK를 설치하고 즐겨찾기·목록·테마·EQ·대기열·위치가 유지되는지 확인합니다.
3. 공개 YouTube 영상의 실제 소리 출력을 사람이 확인합니다. 30분 이상 화면을 잠그고 알림·이어폰의 재생/일시정지/이전/다음 동작을 확인합니다.
4. Wi-Fi와 모바일 데이터 전환, 비행기 모드 후 복구, 사용자가 일시정지한 상태에서의 재연결을 검사합니다. 마지막 경우 자동 재생하면 실패입니다.
5. 전화 수신·종료, 블루투스 분리·재연결을 검사합니다. 사용자의 재생 의도를 무시하고 소리가 나오면 실패입니다.
6. PCM16/float 제공 콘텐츠, EQ/공간 음향 전환, −12~+6 dB 곡 음량, 0.25·1.33·4배속, A–B 반복 해제·곡 변경을 확인합니다.
7. 취침 페이드, 현재 곡 종료 타이머, 타이머 취소 후 음량 복원을 확인합니다.
8. 기록·목록 삭제 취소의 원래 순서/위치, 통합 검색, 추천 제외, LRC 시간 보정, 확장/구형 백업의 선택 복원을 확인합니다.
9. 글꼴 200%, 가로 화면, TalkBack으로 목록 읽기와 대기열 이동을 검사합니다.
10. 캐시 상한 축소·비우기, 긴 대기열(200곡)의 앱 메모리·배터리 사용을 측정합니다. 스트림 목표 8 MiB는 앱 전체 RAM 상한이 아닙니다.

각 결과에는 앱 버전·기기·Android 버전·성공/실패·재현 조건을 기록합니다. 로그인·유료·연령 제한·봇 확인 요구는 우회하지 않습니다.
