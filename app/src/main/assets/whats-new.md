## AudioFlow 1.9.0

- 재생 시작 시 음향 처리기가 빈 버퍼를 자기 자신에게 복사하면서 재생이 중단되는 오류를 수정했어요.
- 이퀄라이저와 공간 음향 처리는 유지하면서 빈 입력만 건너뛰도록 고쳤어요.
- 앱 업데이트 화면을 열거나 다시 돌아오면 정식 최신 버전을 자동 확인해요.
- 새 버전과 현재 버전의 개선사항을 업데이트 화면에서 바로 볼 수 있어요.
- 민트·오션 블루·라벤더·로즈·앰버 테마를 선택할 수 있고, 다크·라이트 모드와 함께 저장돼요.
- 설정을 항목별 화면으로 정리하고, 플레이어의 음향 설정과 재생 종료를 더보기 메뉴로 옮겼어요.
- 네트워크 연결 복구 후 최대 두 번 이어 재생하며, 음질·오디오 전용·디스크 캐시·다음 곡 준비 범위를 선택할 수 있어요.
- 미니 플레이어에 다음 곡을 추가하고, 기록·목록·즐겨찾기 제외 후 실행 취소를 지원해요.
- 라이브러리 전체 검색, 추천 곡·채널 제외, 노래 버전 후보와 대표 선택을 추가했어요.
- A–B 반복, 위치 북마크, 곡별 음량·전체 프리앰프, 현재 곡 종료 타이머와 취침 페이드를 지원해요.
- 내 LRC 가사, 공개 자막 언어 선택과 곡별 시간 보정, 설정·기록·대기열을 선택하는 확장 백업을 지원해요.
- 재생 상태와 라이브러리 작업을 분리하고 대기열 위치 저장을 가볍게 바꿨어요. 구형 설정과 백업도 읽을 수 있어요.
- 자동 음량 정규화와 두 곡을 겹치는 크로스페이드는 실험 과제로 남아 있어요. 실기기 대신 에뮬레이터로 검증한 버전이에요.
