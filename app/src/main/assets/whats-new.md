## AudioFlow 1.9.0

- 네트워크 연결 복구 후 최대 두 번 이어 재생하며, 일반·데이터 제한 연결별 음질, 오디오 전용 스트림, 디스크 캐시와 다음 곡 준비 범위를 선택할 수 있어요.
- 미니 플레이어에 다음 곡을 추가하고, 기록·목록·즐겨찾기 제외 후 실행 취소를 지원해요.
- 라이브러리 전체 검색, 추천 곡·채널 제외, 노래 버전 후보와 대표 선택을 추가했어요.
- A–B 반복, 위치 북마크, 곡별 음량·전체 프리앰프, 현재 곡 종료 타이머와 취침 페이드를 지원해요.
- 내 LRC 가사, 공개 자막 언어 선택과 곡별 시간 보정, 설정·기록·대기열을 선택하는 확장 백업을 지원해요.
- 재생 상태와 라이브러리 작업을 분리하고 대기열 위치 저장을 가볍게 바꿨어요. 구형 설정과 백업도 읽을 수 있어요.
- 큰 글씨와 가로 화면에서 설정을 스크롤하고 대기열의 곡 이동을 접근성 동작으로 사용할 수 있어요.
- 음질 변경 시 같은 스트림의 형식이 섞이지 않게 고쳤으며, 기존 빈 버퍼 재생 중단 수정·테마·최신 버전 자동 확인 기능도 포함해요.
- 자동 음량 정규화와 두 곡을 겹치는 크로스페이드는 실험 과제로 남아 있어요. 실기기 대신 에뮬레이터로 검증한 버전이에요.
